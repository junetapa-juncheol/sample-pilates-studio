# 여백온 필라테스

가상 업체 포트폴리오 샘플입니다. 실제 업체의 영업·상담·모집·서비스가 아닙니다.

필라테스 스튜디오의 수업·예약·이용권 체험 홈페이지입니다. 차분한 오트밀과 우드색으로 구성합니다.

## 쪽 목록

- `index.html` — 첫 화면
- `about.html` — 공간 소개
- `schedule.html` — 날짜별 수업·예약
- `mypage.html` — 예약·취소·결제 기록
- `payment.html` — 이용권·모의 결제
- `complete.html` — 결제 완료
- `contact.html` — 문의 미리보기
- `admin.html` — 통계

## 기능 체험

회원 체험에서 준비된 데모 계정 선택 → 동의 후 체험 가입 → 날짜·수업 예약 → 마이페이지에서 취소 → 이용권 선택·모의 결제 → 완료·통계 확인. 데모 로그인·로그아웃, 중복 예약 방지, 정원 마감, 통계 초기화를 제공합니다. 실제 청구는 0원이며 회원·예약·결제 정보는 현재 브라우저 localStorage에만 보관됩니다. 완료 쪽은 해당 브라우저의 결제 기록에 포함된 주문 주소로 열어야 합니다. 정원은 공유 서버가 없는 예시입니다.

## 사용 기술

HTML5 · CSS3 · Vanilla JavaScript. 글꼴은 Google Fonts의 Noto Sans KR을 요청하며 글꼴 파일은 저장소에 포함하지 않습니다. 글꼴을 가져올 수 없으면 시스템 sans-serif를 사용합니다. 키보드 포커스·모바일 메뉴·움직임 줄이기 설정을 지원합니다. 분석 스크립트·외부 폼·결제 연동이 없습니다.
